# Hunar.ai Hiring Assignment

This repository contains my complete submission for the Hunar.ai hiring assignment.

## Assignments

### Assignment 1 — AI Hiring Assistant
An AI-powered hiring assistant built using Hunar.ai Voice Agents.

### Assignment 2 — People Search & Reachout
A people search and recruiter outreach application with search, filtering, candidate details, and outreach functionality.

> **⚠️ IMPORTANT — DEMO DATA**
>
> The deployed Assignment 2 application currently uses a **demo data provider** so the application can be tested reliably without requiring external third-party API credentials.
>
> The demo data is included in the repository and is intended specifically for evaluation/testing.
>
> **If you would like to test the application with a live people-data provider instead, I can switch the provider configuration and redeploy the application.**

### Assignment 3 — Workplace Attendance System
A system design for attendance management across 1,000 employees and 100 locations where employees do not have smartphones.
The design uses workplace attendance terminals, RFID/NFC badges, PIN fallback, optional biometrics, an attendance system as the source of truth, and an LLM assistant for interacting with attendance data.
